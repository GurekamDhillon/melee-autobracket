# Provenance

Rule from the workspace (`menu/CLAUDE.md`): nothing is traced, sampled, recoloured or referenced from Melee or any
Nintendo/HAL asset; every pixel is generated from source in the workspace repo. Images below were also viewed
before inclusion.

| item | status |
|---|---|
| tokens.css (hex values, sizes, motion) | original (owner/agents) |
| Party pack palette, shapes, motifs, spec text | original (owner/agents) |
| Atlas palette and chamfer language | original (owner/agents) |
| Hub palette (cobalt/gold, shear) | original (owner/agents) |
| refs/parts-sheet.png, refs/envoy-*.png | original (owner/agents): vector mocks generated by `menu/out_envoy/build_final.py`; fighters are placeholder silhouettes with invented names; the retail main-menu mock is excluded |
| Bricolage Grotesque | redistributable, SIL OFL 1.1 (not bundled; load from Google Fonts) |
| Source Sans 3 | redistributable, SIL OFL 1.1 (not bundled) |
| Barlow Condensed, Hasklug Nerd Font | redistributable, SIL OFL 1.1 (not bundled; Atlas only) |
| Disc fonts | derived from disc (not shipped); the Envoy UI does not use them, so no look-alike is needed |
| In-game screenshots and GIFs (portraits, stock icons, stage art) | derived from disc (not shipped); local only in the workspace `scratch\envoy-ui-refs\` |
